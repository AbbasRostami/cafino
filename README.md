## 🎯 Project Overview

**Cafino (کافی‌نو)** is a comprehensive and modern platform for cafe and restaurant management, developed using the latest web technologies. This project consists of two main parts: **Frontend** (Next.js) and **Backend** (Nest.js).

- **Developer**: [alireza-msvi13](https://github.com/alireza-msvi13)

## ✨ Key Features

### 🛒 Customer Features

- 🏠 **Homepage** with category display and popular products
- 🍽️ **Complete menu** with advanced filters (price, category, rating)
- 🛒 **Shopping cart** with add/decrease/remove item capabilities
- 💳 **Integrated payment system** with discount code support
- ❤️ **Favorites** for saving preferred products
- 📍 **Address management** with province and city selection
- 📦 **Order tracking** with complete details
- 🎫 **Ticket system** for support
- 👤 **User profile** with personal settings
- 🌙 **Dark mode** with theme switching
- 📱 **Responsive design** optimized for mobile and desktop

### 👨‍💼 Admin Dashboard Features

- 📊 **Overview & Analytics** with statistics and insights
- 🍽️ **Item Management** (create, update, delete menu items with image uploads)
- 📂 **Category Management** to organize menu items
- 👥 **User Management** and role system
- 📝 **Comment Management** and approval/rejection
- 🎫 **Support ticket management**
- 💰 **Discount Management** and discount codes
- 📦 **Order Management** and status changes
- 🚫 **Blacklist Management** and restrictions
- 📈 **Sales reports** and revenue
- 📊 **Rate Limiting** monitoring and control
- 💬 **Message Center** for customer contact form submissions

### 🛡️ Security Features

- 🔐 **Two-factor authentication** with OTP
- 🛡️ **Access management** based on roles (RBAC)
- 🚫 **Rate limiting system** to prevent abuse
- 🔒 **Route protection** with Middleware
- 🍪 **Secure cookie management**
- 🛡️ **Content Security Policy** configured for service worker
- 🔒 **Security Headers** (XSS protection, frame options, referrer policy)
- ✅ **Input Validation** with Zod schema validation

---

### 🔐 Authentication & Authorization Features

The application uses a cookie-based authentication system with role-based access control:

- **OTP Authentication**: Phone number-based OTP login system
- **Token Refresh**: Automatic access token refresh
- **Role-Based Access**: User and Admin roles with different permissions
- **Route Protection**: Middleware-based route protection for `/profile` and `/dashboard` routes
- **Guest Support**: Full functionality for non-authenticated users

---

## 🛒 Shopping Cart System Features

The cart system supports both guest and authenticated users with seamless experience:

- **Guest Cart**: Local storage-based cart for unauthenticated users
- **Authenticated Cart**: Server-synced cart for logged-in users
- **Cart Migration**: Automatic migration of guest cart to server upon login
- **Real-time Updates**: Immediate UI updates with optimistic rendering
- **Persistence**: Cart data persists across browser sessions

## 🧪 Testing

### 🔬 Unit Tests

Tests are written using Vitest and React Testing Library:

- **Component tests** in `src/components/__tests__/`
- **Hook tests** in `src/hooks/__tests__/`
- **Service tests** in `src/services/__tests__/`
- **Store tests** in `src/store/__tests__/`

### 🎭 E2E Tests

Playwright tests cover critical user flows:

- **Authentication flows** - Login, logout, OTP verification
- **Shopping and checkout process** - Add to cart, checkout, payment
- **Admin panel operations** - Dashboard, item management
- **Navigation testing** - Menu navigation, responsive design

---

### 🔒 Security Features

- **Content Security Policy**: Configured for service worker
- **Security Headers**: XSS protection, frame options, referrer policy
- **Authentication Middleware**: Protected routes with role-based access
- **Rate Limiting**: API rate limiting support
- **Input Validation**: Zod schema validation on all forms
- **Cookie Security**: HttpOnly cookies for token storage

### 📂 Key Folders Explanation

- **`app/`**: Next.js App Router with route groups for different user types
- **`components/`**: React components with modular structure
- **`services/`**: API calls and business logic hooks
- **`hooks/`**: Custom React hooks for reusable logic
- **`store/`**: Zustand state management with persistence
- **`types/`**: TypeScript type definitions organized by feature
- **`utils/`**: Helper functions and utilities
- **`schemas/`**: Zod validation schemas for form validation

### 🔄 Data Flow

- **`Client-Side/`**: React Query for caching and state management
- **`Server-Side/`**: Next.js API Routes for proxy
- **`Authentication/`**: JWT tokens with httpOnly cookies
- **`Authorization/`**: Role-based access control (RBAC)
- **`Caching/`**: Multi-layer caching strategy
